# خطة الانتقال من Google Sheets إلى Supabase

- تبقى تطبيقات Google Sheets الحالية دون تغيير أثناء العمل.
- تُنشر نسخة Supabase على رابط اختبار مستقل.
- تُسجل بيانات تجريبية فقط في البداية.
- تُختبر صلاحيات الطالب والمشرف والنقاط والحضور والمجموعات.
- لا يتم تحويل الطلاب إلى النسخة الجديدة حتى اعتماد الاختبارات.
- بعد الاعتماد تُستورد بيانات الطلاب، ثم تُحدث روابط الاستخدام.
